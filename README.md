# Визуализатор графа зависимостей (Cargo)
## 1. Общее описание
CLI - инструмент для анализа и визуализации графа зависимостей пакетов Rust. Зависимости получаются собственной реализацией, без менеджеров пакетов и сторонних библиотек для работы с зависимостями.

**Текущий этап: 1 - минимальный прототип с конфигурацией.** Приложение читает XML-конфигурацию, проверяет параметры и выводит их в формате "ключ: значение".

## 2. Функции и настройки
```
depgraph [путь/к/config.xml]
```
Если путь не указан, используется `config.xml` из текущего каталога.
Флаг `-h` / `--help` выводит справку.

### Параметры `config.xml`
`package_name` - имя анализируемого пакета
`repository` - URL репозитория или путь к файлу тестового репо
`mode` - режим работы с репозиторием: `remote` или `test`

### Правила проверки
`mode` - значение `remote` или `test`
`package_name` - `remote`: имя Cargo (латинская буква, затем буквы, цифры, `-`, `_`, до 64 символов); `test`: только большие латинские буквы `A-Z`
`repository` - `remote`: корректный URL со схемой `http`/`https` и хостом; `test`: существующий читаемый файл

Дополнительно проверяются: наличие и читаемость файла конфигурации, корректность XML (с указанием строки и столбца), корневой элемент `<config>`, отсутствие неизвестных, повторяющихся и пустых параметров. DOCTYPE запрещён (защита от XXE).

### Коды возврата
0 - успех
1 - ошибка конфигурации
2 - неверные аргументы командной строки
